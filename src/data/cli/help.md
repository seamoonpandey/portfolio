# Available Commands

- \`ls\`: List available files (modules).
- \`cat [file]\`: Display content of a file.
- \`help\`: Show this help message.
- \`clear\`: Clear the terminal screen.
- \`whoami\`: Print current user.
- \`exit\`: Return to GUI mode.

## Shortcuts

- \`about\`: Alias for \`cat about.md\`
- \`projects\`: Alias for \`cat projects.md\`
- \`skills\`: Alias for \`cat skills.md\`
- \`contact\`: Alias for \`cat contact.md\`
